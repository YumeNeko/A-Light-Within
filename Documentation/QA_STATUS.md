# 《心灯》独立版验证状态

更新：2026-09-16。工程位置：`D:\工程文件\Unity\A Light Within（心灯）`。

当前结论：**独立工程和 Windows 试玩版均已成功构建，最终包体通过 73 项自动运行时检查，可以进入作者真实键鼠验收。** 源码已经上传至公开 GitHub 仓库，Windows 试玩 ZIP 已作为 `v1.0.0` Release 发布。

## 本轮改动

- 开始页仅保留中英文游戏名、操作说明、开始与退出按钮。
- HUD 删除固定左上区域说明、右上计数牌和右下操作说明；左下能力块改为三个 64×64 的紧凑方块。
- 统一将界面文字改为允许完整溢出显示，修复中文字体下沿被裁切的问题。
- 四个区域改为顶部无边框文字提示，进入区域后显示三秒并淡出。
- 所有通知和交互提示去除深色底框，以带轻微阴影的透明文字显示。
- 机关统一为单击 E；删除长按进度、注入连线、H 键逻辑、H 文案和失效配置字段。
- 三块浮台使用不同相位，纵向摆幅约 0.72 / 0.81 / 0.90 米，并加入 0.1 米轻微上下摇摆。
- 结算页只保留游戏名、主题句、旅途用时、心灯计数、再来一次和退出游戏。
- 删除新副本中的旧课程场景、旧场景生成器、13 个未使用运行脚本、4 个课程交付脚本及 131 个未引用资源。
- 构建工具缩减为当前独立场景的验证与 Windows 构建；输出固定在工程内 `Builds/Windows`。
