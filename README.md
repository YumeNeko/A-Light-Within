# A Light Within（心灯）

## 项目简介

一款使用 Unity 开发的第三人称探索解谜游戏原型，玩家需要领悟并正确运用“洞察、共鸣、勇气”三种能力，通过机关、危险区域和最终谜题完成角色成长旅程。

## 技术栈

- Unity 6000.3.10f1
- C#
- Unity Input System
- Cinemachine
- ScriptableObject 数据配置
- CharacterController 与 Unity Physics

## 运行说明

### 直接运行 Windows 版本

1. 进入仓库右侧的 **Releases** 页面。
2. 下载最新版本中的 `A-Light-Within-Windows.zip`。
3. 完整解压 ZIP 文件。
4. 双击 `A Light Within.exe` 启动游戏。

请勿单独移动 EXE；程序需要与 `A Light Within_Data`、`MonoBleedingEdge` 和其他运行文件保存在同一目录。

### 在 Unity 中打开

1. 使用 Unity Hub 安装 Unity `6000.3.10f1` 和 Windows Build Support。
2. 克隆或下载本仓库。
3. 导入 Unity Starter Assets 第三人称组件。
4. 打开 `Assets/Heartlight/Scenes/Heartlight.unity`。
5. 点击 Play 运行，或通过 `心灯 → 构建 Windows 试玩版` 重新构建。
